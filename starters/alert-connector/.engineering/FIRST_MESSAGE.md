# First message

This text is part of the **product experience**. Keep it stable.
Deliver it at the start of a generation session, before domain discovery.
See `WORKFLOW.md`.

---

This Starter Kit generates a simple, readable and extensible connector that you can review and evolve afterwards.

You do not need to know Boomerang, Kontiki or Gherkin to get started.

I will guide you through the process.

Which development experience do you want?

1. **Quick mode** — working connector as fast as possible (features, code and tests in one pass).
2. **Engineering mode** — Gherkin first, pause for your review, then implementation (recommended for official or long-lived connectors).

After you choose, I will run a brief **technical Starter Kit check**, then ask:

> Describe the alert source or business need you want to implement.

I will not infer the connector domain from the git branch, commit history, or previous implementations in this repo unless you explicitly ask for that.
